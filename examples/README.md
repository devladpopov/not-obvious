# Examples

Ready-to-paste configs. Replace `...` with your keys. Every setup also works with the CLI: put the same variables in your shell and run `npx -p not-obvious-mcp not-obvious map "your prompt"`.

| File | Setup |
|---|---|
| [`claude-desktop.json`](claude-desktop.json) | Claude Desktop with Claude + Gemini (the setup the leaderboard and calibration used) |
| [`claude-code.sh`](claude-code.sh) | Claude Code, one command |
| [`cursor-mcp.json`](cursor-mcp.json) | Cursor (`.cursor/mcp.json`) with a Claude key and OpenRouter models for a wider cloud |
| [`ollama-local.json`](ollama-local.json) | Fully local: Ollama models, local embeddings, no web check, no keys |
| [`session.md`](session.md) | What a session looks like: the `not-obvious` prompt, map, diverge, explain |
